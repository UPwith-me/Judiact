# DiagSafe-VL 当前数据

本文依据 2026-10-12 读取的冻结发布和 v3 训练清单整理。当前使用 `releases/v3_train_dev_20261008`，父发布为 `first_round_20261007`。本文记录数据组成和使用方式，文件中的复核历史继续保存在内部。

阅读字段定义时使用 [数据契约](../data_contract/v1/README_ZH.md)，阅读训练中的监督方式时使用 [v3 方法](DIAGSAFE_V3_METHOD_EXECUTION_PLAN_20261008_ZH.md)。

## 1. 数据解决什么问题

我们需要知道模型是否理解当前可见图文、怎样应用实际规则，以及候选回答是否会执行或扩大风险。数据同时保留完整审核标签和已核实输入变化，让每个具体判断及其变化都能得到监督。

自然请求覆盖常规帮助、敏感分析、风险请求和信息不足的边界情境。关系组围绕视觉证据、图文绑定、意图、规则和回答执行设计。原生辅助提供更广泛的安全监督，使用范围按来源真实标签确定。

## 2. 数量的口径

根情境表示归并后的原始请求背景。成员是该根下的一条具体输入，图片、请求或规则变化可能产生多个成员。回答候选按条计数，相同可见请求下的多条回答归到同一上下文。

有效组、关系边和 S2 四角分别计数。一个组可以包含多条边，同一根也可以承载多个组。展开审核问题属于训练视图，统计规模时仍保留其父成员和根。

## 4. 来源和请求构造

Core 的文本来源包括 WildGuardMix、Aegis 2.0、SPA-VL 和 VLGuard，也包含项目逐条编写的自然请求。图片来源包括 LLaVAGuard-SMID、VLGuard、GuardReasoner-VLTrain-Image、SPA-VL 和 Wikimedia Commons。

| 图片来源 | Core 中出现的图片槽位数 |
| --- | --- |
| LLaVAGuard-SMID | 899 |
| VLGuard | 479 |
| GuardReasoner-VLTrain-Image | 437 |
| SPA-VL | 152 |
| Wikimedia Commons | 1198 |

槽位数按所有成员中每张输入图片的出现次数计算，其中含同图变体、多图输入和裁切。同源重复与独立图片支持集另由媒体和根家族整理记录。

当前 Core 的 `query_provenance` 记录 2221 条来源原请求、2685 条项目逐条编写请求、4 条截断来源的替代请求，以及 165 条其他已说明来源的请求。图片来源保存于 `images`，请求来源保存于 `source`，两者可以不同。

普通带图输入只提供图片像素和自然 query，人工 OCR、caption 和构组目标留在模型提示之外。OCR-only 保留自然 query 和真实转写。裁切图片只保留原始像素，内部保存原图与裁切坐标。

## 6. 因果关系与 S2 四角

已有建设记录中的非零、规则边界或回答执行差异组按 S1-S5 为 120、152、90、121、143，共 626 组。组内成员、零交互对照和规则不变性另计。

当前实际关系文件包含 2281 条核实边、1017 个进入训练的关系组 ID，归入 734 个请求根或回答上下文簇。这个更广的关系集合包含控制与不变性任务，统计口径与 626 个有效差异组分别保留。

| S2 四角类别 | 组数 |
| --- | --- |
| 确定的非零交互 | 152 |
| 确定的零交互对照 | 77 |
| 含不确定角 | 83 |
| 合计 | 312 |

四角索引明确引用四个成员，各角独立标签和实际输入共同决定关系。已确定的非目标稳定记录目前只支持 F 字段，R/E 的监督继续来自各成员标签。

S4 将真实规则边界变化与规则顺序、ID 不变性分开。S5 的执行关系要求相同可见请求以及实际成立的回答执行差异。

## 7. 开发集与划分

自然 dev 包含 299 条请求和 200 条回答审核。完整 dev 文件包含 457 条请求成员和 232 条回答成员，合计 689 条，包含自然部分及机制成员。请求与回答的分母分别保留。

train、dev、test_hidden 按根图、来源记录、确认的近重复和 query 模板家族隔离，再在各集合内部形成变体。原图与裁切放在同一 split。外部 benchmark 保持评测用途，隐藏测试保持封存。

当前版本保留全量人工终审尚未认证的状态，以及父发布近重复核验的已知缺口。既有审计曾记录 425 个训练图片条目缺少缓存近重复向量，该项后续完成情况需要单独核对。本文中的数量表示已进入冻结工作集的记录。

## 9. 后续数据建设

后续参考规模保留 Core 6000 个根、S5 3000 条回答和约 2000 个有效因果训练组。当前版本的覆盖与规模充分性仍需研究证据支持。

新增工作优先补真实视觉必要情境、不同图文关系、hard benign、warn/review、薄弱危害类别、真实规则边界和图文回答执行差异。普通文本扩量和同图重复不会增加这些情境的覆盖。

纠错继续依据可见输入与字段定义进行，关系有效性与成员标签分别核对。关系不成立但成员标签可靠的记录可以继续用于绝对监督。
